# Evidence / 效果图

本目录用于存放验收截图。截图**不含任何身份信息**（序列号、用户名、MAC、内网地址），可安全公开。

建议至少放这几张：

1. **`01-about-this-mac.png`** — 「关于本机」：显示 `AMD Ryzen 9 7940HS` 与 `MacPro7,1`，证明 CPU 名称补丁与 SMBIOS 生效。
2. **`02-displays-metal3.png`** — 系统信息 → 显示器/图形卡：显示 `AMD Radeon 780M`、`Metal 3`、Device ID `0x15bf`。
3. **`03-liquid-glass-dock.png`** — 桌面 + Dock + 菜单栏，体现 M2 Liquid Glass 半透明玻璃效果（Dock 透出壁纸）。
4. **`04-system-settings-translucency.png`** — 系统设置窗口的半透明材质。
5. **`05-airdrop.png`**（可选）— 隔空投送能搜到设备，证明 AWDL/AirDrop 工作。

## 命名与格式

- PNG 优先，文件名用 `序号-简短说明.png`
- 截图前确认状态栏/窗口里没有邮箱、用户名、内网 IP 等隐私信息
- 放进来后在本 README 里补一句图注即可

> 当前目录暂无图片。截图由机器主人后续补充并单独提交（本地环境无屏幕录制权限，无法代为截取）。
